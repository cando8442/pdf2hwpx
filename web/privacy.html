이 서비스는 서버가 없습니다. 모든 처리가 이용자의 브라우저 안에서 일어나며, 제작자는 이용자의 파일도 개인정보도 수집하거나 보관하지 않습니다. 다만 수식을 판독하기 위해 이용자가 직접 입력한 API 키로 변환할 페이지 이미지를 AI 판독 서비스에 보내는 과정이 있어, 그 내용을 아래에 밝힙니다.

1수집하는 개인정보와 수집 방법

이 서비스는 회원가입·로그인이 없으며 개인정보를 수집하지 않습니다. 이름·학번·연락처를 입력받는 곳이 없고, 접속 기록을 남기는 서버도 두지 않습니다.

다만 서비스를 쓰려면 아래 두 가지가 이용자 브라우저에만 저장됩니다. 이 값은 제작자에게 전송되지 않으며 제작자는 볼 수 없습니다.

저장 위치이용자 기기의 브라우저 저장소(localStorage) pdf2hwpx.key / pdf2hwpx.model / pdf2hwpx.remember
저장 목적다시 방문했을 때 키를 매번 입력하지 않게 하기 위함
저장하지 않기준비 화면의 “이 브라우저에 키 기억하기” 체크를 해제하면 저장하지 않습니다

변환에 넣은 PDF 파일 자체는 브라우저 메모리에서만 다뤄지며 어디에도 저장되지 않습니다. 탭을 닫으면 사라집니다.

2처리 목적

  • PDF 학습지를 한글 문서(hwpx)로 변환하는 것, 그 하나의 목적으로만 처리합니다.
  • 광고·마케팅·프로파일링·통계 분석에 이용하지 않습니다.
  • 접속 통계나 이용 행태를 수집하는 분석 도구(Google Analytics 등)를 넣지 않았습니다.
  • 쿠키를 사용하지 않습니다.

3보유 및 이용 기간

API 키·모델 선택이용자가 지울 때까지 그 브라우저에 남습니다. “키 지우기” 버튼이나 브라우저의 사이트 데이터 삭제로 즉시 지울 수 있습니다.
변환한 PDF·결과 파일브라우저 메모리에만 존재하며 탭을 닫으면 사라집니다. 서버에 남지 않습니다.
제작자 보유분없음. 제작자는 어떤 데이터도 받지 않으므로 보유하는 것이 없습니다.

4제3자 제공

이용자의 개인정보를 제3자에게 제공하지 않습니다. 판매·대여·공유하는 일이 없습니다.

5처리 위탁 및 국외 이전

서비스 운영에 다음 두 곳을 이용합니다.

Netlify, Inc. 웹사이트 호스팅(미국). 정적 파일을 내려주는 역할만 하며, 이 서비스는 서버로 데이터를 보내지 않습니다. 접속 시 통상적인 웹 요청 기록(IP 등)이 호스팅 사업자 측에 남을 수 있습니다.
Anthropic PBC AI 수식 판독(미국). 이용자가 “읽기 시작”을 누른 경우에만, 선택한 PDF 페이지의 이미지가 api.anthropic.com 으로 전송되어 수식이 판독됩니다. 전송은 이용자 자신의 API 키로 이용자 브라우저에서 직접 이루어지며 제작자를 거치지 않습니다. 전송된 내용의 취급은 Anthropic 의 정책을 따릅니다.

따라서 개인정보가 담긴 문서를 넣지 마시기 바랍니다. 이 도구는 교사가 만든 학습지·문제지를 변환하기 위한 것이며, 학생의 이름·답안 등이 담긴 자료를 넣는 용도로 만들어지지 않았습니다.

6정보주체의 권리와 행사 방법

이 서비스는 제작자 측에 보관하는 개인정보가 없으므로, 저장된 값에 대한 권리는 이용자가 자신의 브라우저에서 직접, 즉시 행사할 수 있습니다.

  • 열람 — 준비 화면의 키 입력란에서 저장된 값을 확인할 수 있습니다.
  • 정정 — 입력란의 값을 고치면 즉시 반영됩니다.
  • 삭제 — “키 지우기” 버튼을 누르면 즉시 삭제됩니다.
  • 처리 정지 — “이 브라우저에 키 기억하기” 체크를 해제하면 이후 저장하지 않습니다.

그 밖의 문의나 이의 제기는 아래 8항의 보호책임자에게 하실 수 있습니다.

7안전성 확보 조치

  • 수집하지 않는 것이 가장 큰 안전조치입니다. 서버와 데이터베이스를 두지 않아 유출될 보관 정보가 없습니다.
  • 모든 통신은 HTTPS 로 암호화되며, HSTS 로 평문 접속을 막습니다.
  • 콘텐츠 보안 정책(CSP)으로 외부 스크립트 주입을 차단하고, 통신 대상을 판독 서비스로 한정합니다.
  • 다른 사이트가 이 화면을 몰래 끼워 넣지 못하도록 클릭재킹 방어를 적용했습니다.
  • API 키는 코드에 넣지 않으며, 이용자 브라우저 저장소에만 두고 제작자에게 전송하지 않습니다.
  • 카메라·마이크·위치 등 브라우저 권한을 일절 요청하지 않으며 정책으로도 차단했습니다.
